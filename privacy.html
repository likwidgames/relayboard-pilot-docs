Local pilot privacy notice

Operator: Mike Wojcik (GitHub account: likwidgames). This notice describes the current local hosting pilot. Effective November 1, 2026.

Information used

With the owner’s authorization, the pilot uses connected account and project identifiers, selected repository metadata, workflow and environment settings, release and deployment records, and authentication credentials needed for the approved connection. The broader task workflow also stores owner requests, answers, source proposals, decisions, checks and usage records.

Why it is used

This information supports connecting the selected project, preparing and verifying approved work, maintaining task history, enforcing usage limits and retaining failures or uncertain results for review.

Local storage

Task and decision records are stored in the local Relayboard PostgreSQL database. Remembered connection credentials are encrypted locally using AES-256-GCM, with the encryption key protected by macOS Keychain. This local vault is not a claim of hosted SaaS secret-storage readiness.

Provider processing

GitHub and Vercel process the information required for authorized source, hosting and release operations. If the owner separately enables an AI task, the selected provider receives the task materials needed for that request. Those providers apply their own policies and account settings. Connecting hosting alone does not start an AI task.

Private-site verification

Approved setup may create integration-owned access to verify this project’s protected deployments. Required hosting credentials are encrypted for storage in the reviewed GitHub environments. Existing secret values are not read back by the setup flow. Credential values are not placed in public setup history, task comments or the frontend.

Retention and disconnecting

The pilot retains task history, exact owner decisions, failed attempts and uncertainty evidence. Disconnecting or forgetting a local connection does not delete this history, remove existing GitHub secrets or erase provider records. Deletion requests and provider-access revocation should be addressed with the operator and the relevant provider; no automatic deletion deadline is promised by this pilot.

Other use and contact

The local pilot does not add advertising analytics or sell pilot data. Questions about access, correction or retention can be raised with the operator through the existing pilot support channel. This notice must be reviewed before use outside the internal pilot.
