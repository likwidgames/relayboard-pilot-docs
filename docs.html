Connect hosting once

Relayboard helps a project owner coordinate software work on a board. This local pilot connects an existing code repository and Vercel project so the team can prepare reviewed releases.

Connect your project

  1. Open Relayboard Setup and connect the existing GitHub App. Choose access to the notes pilot repository.
  2. Choose Connect Vercel. In Vercel, grant access only to the hosting project used by this pilot.
  3. Choose the project in Relayboard and review the one-time connection setup. Read the proposed changes before approving.

What Relayboard handles

Relayboard reads the existing hosting and workflow settings, checks that they match the reviewed configuration, and prepares the missing connection settings. With your setup approval, the server encrypts required credentials directly into the reviewed GitHub environments. Credential values do not appear in the task conversation.

Release decisions stay yours

Connection setup does not publish your website. You accept completed source work before delivery, and Production requires a separate approval for the exact reviewed version.

When setup needs attention

Missing access, changed settings or an unconfirmed provider response pauses the affected step and retains its history. Relayboard does not blindly repeat an uncertain write or start work when reopened.

Current pilot scope

The pilot uses installed, reviewed GitHub Actions workflows with an existing Vercel project. Live hosting authorization and setup are still awaiting their first integration exercise. Other hosting providers, new-project provisioning and a commercial hosted service are future work.

Operator support

This is an internal pilot operated by the owner of the likwidgames GitHub account. Contact that operator through the existing channel used to arrange the pilot.
